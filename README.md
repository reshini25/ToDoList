# 📝 Flutter To-Do List App

A simple and beautiful **To-Do List** mobile app built using **Flutter**.  
This app helps users manage their daily tasks efficiently with an easy-to-use interface.

---

## 🌟 Features
- ➕ Add new tasks  
- ✏️ Edit existing tasks  
- ✅ Mark tasks as completed  
- ❌ Delete tasks  
- 💾 Save tasks locally using `shared_preferences`  
- 🕶️ Clean and minimal UI


## 🧠 Tech Stack
- **Framework:** Flutter  
- **Language:** Dart  
- **State Management:** setState / Provider (choose what you used)  
- **Storage:** Shared Preferences or SQLite
